CUHK 校巴 UI 与动效样品

默认展示 A 浅色 / F 深色双模式，顶部及侧边栏均可切换。
两种模式使用同一地图与日程状态；切换时不重置当前选择。
其他设计方案仍可通过顶部样品组入口对比。

可直接打开 index.html，也可通过静态网站访问。
线上地址：https://hainahuang729.github.io/cuhk-map/demos/ui-modes/

到站时间、天气、课程和营业时间均为演示内容，不是实时资料。
本样品不连接云端、不读取 GPS、不发送广播、不上传或持久保存个人数据。
导航路径仅用于展示交互和样式，不是完整的在线路径规划服务。
此目录不替换正式网页或微信小程序，不包含本地 GPS 行程或上传记录。

公开校园地图数据：OpenStreetMap contributors，ODbL。

Lucide 0.468.0，详见 assets/lucide-LICENSE.txt。
